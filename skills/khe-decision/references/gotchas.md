# Gotchas

This file is **append-only**. Each time a council run seats the wrong brain, lets a seat see another, puts a guess beside a name or trips on a gate line that fired wrongly, add a one-line gotcha here. Do not edit an entry unless it is outright wrong.

A fault inside one brain (a wrong time, a stretched line, a dead link) belongs in that brain's own `gotchas.md`. This file is for faults in how the council itself ran.

## Format

```text
- [YYYY-MM-DD] One-line description of the gotcha. → the fix, and the reference that owns the rule
```

Keep each to one line. Your own calls go in [pov](pov.md), not here.
