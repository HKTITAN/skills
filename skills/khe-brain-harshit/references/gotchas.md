# Gotchas

This file is **append-only**. Each time an answer or a draft gives him a view he did not post, stretches a line past its context, or slips into his old style, add a one-line gotcha here. Do not edit an entry unless it is outright wrong.

## Format

```text
- [YYYY-MM-DD] One-line description of the gotcha. → the fix, and the reference that owns the rule
```

## Entries
