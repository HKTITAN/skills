# Gotchas

This file is **append-only**. Each time an answer reports something the notes do not say, stretches a line past its file or misses a piece, add a one-line gotcha here. Do not edit an entry unless it is outright wrong. Negative examples are the highest-signal content in a skill over time: the instructions should change rarely and this file should grow steadily.

## Format

```text
- [YYYY-MM-DD] One-line description of the gotcha. → the fix, and the reference that owns the rule
```

Keep each to one line. Your own disagreements with the notes go in [pov](pov.md), not here.
