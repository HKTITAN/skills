# Security

Skills here ship scripts that people and agents run, so a fault in one is worth a private report.
Report it through GitHub's private reporting at <https://github.com/HKTITAN/skills/security/advisories/new>. Never open a public issue for it.
What counts: a script that reads or sends more than its job needs, a manifest that installs something it does not name, a credential in the history.
Linked skills (no `khe-` prefix) belong to their authors. Report those in their repos.
