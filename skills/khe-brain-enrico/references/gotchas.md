# Gotchas

This file is **append-only**. Each time an answer reports something he did not say, stretches a line past its product or its year, or misses a video, add a one-line gotcha here. Do not edit an entry unless it is outright wrong. Negative examples are the highest-signal content in a skill over time: the instructions should change rarely and this file should grow steadily.

## Format

```text
- [YYYY-MM-DD] One-line description of the gotcha. → the fix, and the reference that owns the rule
```

Keep each to one line. Your own disagreements with him go in [pov](pov.md), not here.
