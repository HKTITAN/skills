# Film Cheatsheet

| Problem                              | Solution                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------------ |
| Sentence arrives as one block        | Build it per word about `0.2 s` apart, then hold `1.15` to `1.5 s`             |
| Nobody can read the typed prompt     | About `15` characters a second, then a `1.15 s` hold                           |
| Name shows up too late               | By `11 %` of the runtime, or where the problem act ends (median `29 %`)        |
| Endcard leaves before it is read     | `4.4` to `6.3 s`, the final frame held about `2 s`                             |
| Cut feels dead                       | Cut mid-motion, or the incoming frame acts within `0.3` to `0.4 s`             |
| Zoom reverses across a cut           | Match the Z sign: scale 1 to `1.2` out, `0.75` to 1 in                         |
| Dissolve flashes in the middle       | Hard cut on the palette change, or a dip through one ground both scenes share  |
| Held card looks like it is waiting   | No float, pulse or breathe: a slow camera push or drift                        |
| Cursor is lost on a wide shot        | Pointer at `7cqw`, exit off the nearest edge                                   |
| Vertical cut is the master with bars | Its own layout: text inside top `270`, right `120`, bottom `420`, left `64 px` |
| Sound cues drift after an edit       | Lock picture first (`picture_locked: true`), then place cues                   |
| Render will not play on a phone      | H.264 `-level 4.2` at 1080p, `5.2` at 4K                                       |
| GIF stutters                         | `25` or `50 fps`, nothing else                                                 |
| Cut count looks wrong                | Count by eye at native fps, contact sheets stepped every `2` frames            |
| The hook lands late                  | A word by `1.3 s`, the first seam by `3.6 s`                                   |
