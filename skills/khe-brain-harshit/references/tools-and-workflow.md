# Tools and workflow

This theme is how he actually works and which tools earn a place in his stack. Since mid-2025 his workflow is built around coding agents: Cursor and Claude Code inside a system of plan mode, rules, skills and markdown documentation, with Notion as the shared workspace for him and his agents, Poke as his daily assistant, and Omi and tldraw at the edges. He judges a tool by whether it reaches his agents (a CLI, an MCP server, an SDK) and whether it runs on Windows and Android, which he uses. His 2022 to 2024 posts are about Notion setups, browsers, note-taking methods and keeping a productivity system simple.

## How does he build software with AI?

- He says he no longer just uses AI to code but builds a system around it: plan mode first, tight context, rules so he does not repeat himself, skills, design-system thinking, testing early and committing often; the leverage is the environment that keeps the model useful long enough to ship, not prompting harder. "vibe coding is not magic" (2026-05-02-asked-clawmani-break-down, https://www.linkedin.com/feed/update/urn%3Ali%3AugcPost%3A7456367896156553216)
- He says to offload the grunt work to the agent and keep the judgment calls. "offload the boring, keep the judgment." (2026-06-01-gap-between-people-who, https://x.com/HarshitKhemani/status/2061415603920044197)
- He says agents matter most because iteration gets cheap: he builds a scrappy version, lives with it, feels what is awkward, throws most of it away and rebuilds, and he gets intuition for a new tool by playing with it. "you don't read your way into intuition." (2026-07-22-know-how-6-y, https://www.linkedin.com/feed/update/urn%3Ali%3Ashare%3A7485749343468011520)
- He says a few markdown files, once you understand how Cursor works, can multiply output; setting rules for Cursor gave him much better output, and vibe-coded projects need documentation that agents or humans can read, which he keeps in Obsidian next to Cursor. "you can really 100x your output with just a few md files." (2026-01-17-if-sit-down-properly, https://x.com/HarshitKhemani/status/2012546328128098729; 2026-01-13-jasonbud-tried-organizing-codebase, https://x.com/HarshitKhemani/status/2011100773950878203; 2026-01-17-cursor-obsidian-vibe-coding, https://x.com/HarshitKhemani/status/2012615443287359681)
- On his game Smash&Clash: AI helped him rewrite the board game from scratch in 50 hours, and when he asked Opus 5.5 to rebuild the game's menus he found it very good at motion design. (2026-06-13-same-helped-rewrite-board, https://x.com/HarshitKhemani/status/2065780501370306909; 2026-09-27-asked-opus-5-5, https://x.com/HarshitKhemani/status/2104226572714832226)
- His practical tips: to clone an app, ask Claude Code to reverse engineer it; to push code, tell Claude to push through the gh CLI with your own id; to give an agent brand rules, hand it a .design file. (2026-07-08-piyushgarg-dev-ask-claude, https://x.com/HarshitKhemani/status/2074815484353270207; 2026-06-18-shrav-10-tell-claude, https://x.com/HarshitKhemani/status/2067610009228464262; 2026-10-26-sainotsoai-atharvavaidya-hand-design, https://x.com/HarshitKhemani/status/2114576404717437434)

(2026-05-09-icanvardar-ai-great-force, https://x.com/HarshitKhemani/status/2052932812177821763; 2026-07-28-hadikhantech-fact-time-flies, https://x.com/HarshitKhemani/status/2082038936185327943)

## Cursor, Claude Code or Codex?

"cursor's ability to create codebase embeddings is on another level."
