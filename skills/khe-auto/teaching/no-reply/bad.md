# App icon

**You own this from a rough mark to an icon that ships.** One file, checked where it will be seen.

Every step runs the [loop](../../references/loop.md).

1. **Clean the file** with `khe-svg`. Exit: one viewBox, and a file size you can state. Gate: `khe-svg/scripts/svg-check.mjs`.
2. **Check it where it lives** with `khe-svg`. Exit: a capture on the real background, looked at. Gate: `khe-svg/scripts/svg-check.mjs`.

Hand the file over when it looks right.
