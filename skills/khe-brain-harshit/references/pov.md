# Point of view

This file is **meant to be edited by him**. The theme files record what he posted and stay as they are. This file is where he says what has changed since, or what he thinks and has not posted. Read it before answering or drafting, beside [gotchas](gotchas.md).

## How to use this file

1. **A view not yet posted.** For example: "every product will ship an MCP server before a mobile app." A draft may rest on it; under the draft it goes on a `Yours:` line, which carries no citation, in place of a `Rests on:` line.
2. **A correction.** For example: "the 2023 view on Notion templates no longer holds." The skill then reports the old post with its date and this line beside it.
3. **What to press on.** For example: "in a pressure-test, check the on-ramp first."

Be specific. "i like games" changes nothing. "i will not add a tutorial to any product i ship" changes a draft.

An entry here is never reported as a post. A reply keeps the two apart: the post with its `(post)`, the entry on a `Yours:` line.
