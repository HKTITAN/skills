# Point of view

This file is **meant to be edited by you**. The rest of the skill is canonical; this is your override layer. Read it before any job, alongside [gotchas](gotchas.md).

## How to use this file

Add calls that override or extend the defaults. Two kinds are useful:

1. **Hard overrides**: "Video projects live in C:/PROJECTS/videos." or "Explainers default to dark."
2. **Taste calls**: "Click-throughs end on the first state so they loop."

Be specific. "Keep it clean" gives the agent nothing.

Three things this file can never override: stills before the render, no real-time capture, and the 2000 and 4096 pixel limits.
