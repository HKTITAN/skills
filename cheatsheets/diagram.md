# Diagram Cheatsheet

| Problem                                   | Solution                                                                            |
| ----------------------------------------- | ----------------------------------------------------------------------------------- |
| Three boxes in a row for one relationship | Delete the figure, ship the sentence                                                |
| Too many boxes to follow                  | `9` nodes at most: an overview of zones, then one path in detail                    |
| Connector runs at an angle                | Horizontal run, quarter curve at `r=8`, vertical run                                |
| Two arrows land on one point              | Own attach points at `L·k/(N+1)`, `12px` or more apart                              |
| Label sits on its line                    | Opaque paper mask `6` to `10px` clear of the stroke                                 |
| One arrow with two heads                  | Solid request, dashed `5,4` reply that starts at the recipient                      |
| Stroke paints on top of a box             | Every connector before the first node in the file                                   |
| Accent on everything                      | One accent hue on `1` or `2` elements, the rest ink, muted or soft                  |
| Boxes look like app cards                 | Radius `6`, type tags `2`, a border, no `filter`                                    |
| Legend floats among the nodes             | Horizontal strip under the figure, `viewBox` extended by about `60px`               |
| Everything is in mono                     | Names in a sans at `600`, mono only for ports, commands, URLs and field types       |
| Type you squint at                        | Names `12px`, sublabels `9px`, connector labels `8px`: delete content, never shrink |
| Boxes sit slightly off each other         | x, y, width and height divide by `4`                                                |
| Arrow detaches when a card is dragged     | `helpers.createArrowBetweenShapes`, never a raw arrow                               |
