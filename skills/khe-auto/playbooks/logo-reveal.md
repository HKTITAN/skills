# Logo reveal or mascot

**You own this from the source file to an asset that ships.** A flat export that happens to move is not the job.

1. **Check for a contract** with `khe-design-tokens`. If the project has a `.design` file or DESIGN.md, its colors and curves are the only ones the file may use.
2. **Make or clean the file** with `khe-svg`. Exit: one viewBox, named groups, token colors, no editor junk, and a file size you can state.
3. **Decide the engine** with `khe-svg`, by where the file will live: inline on a page, used as an image, or inside an app. The engine follows the home, never the other way round.
4. **Animate it** with `khe-svg`. A clip that needs turning into vectors goes through its video-to-vector steps first. Exit: the reveal plays once, ends on the final mark, and has a reduced-motion state that is the finished logo.
5. **Sound, only if it earns one** with `khe-sound`. A reveal seen once can carry a sound. A logo in a header that loads on every page cannot.
6. **Check it where it lives**: at its real size, on its real background, in light and dark.

**Reply:** the file path and size, the engine and why, what the reduced-motion state shows, and what you did not test.
