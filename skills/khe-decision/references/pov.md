# Point of view

This file is **meant to be edited by you**. The rest of the skill is canonical; this is your override layer. Read it before any decision, alongside [gotchas](gotchas.md).

## How to use this file

Two kinds of entry are useful:

1. **Hard overrides**: "Never seat `khe-brain-emil` on a hiring decision." or "My extra brains live in `D:/brains`; pass it with `--brains`."
2. **Taste calls**: "In the recommendation, weigh runway before growth." or "Keep `COUNCIL.md` for every reply, not only the ones I will act on."

Be specific. "Be balanced" gives the chair nothing.

An entry here shapes your synthesis and is never reported as a seated person's view. Each brain has its own `pov.md` for where you part ways with that person; a line from there arrives inside that seat's block on its `Yours:` line.

Four things this file can never override:

- Every line is a seat's cited line or the labelled synthesis (Hard rule 1).
- No council on fewer than two relevant brains (Hard rule 4). An entry can leave a brain out; it cannot seat one whose corpus does not cover the decision.
- Seats never see each other, and the chair never sees a corpus (Hard rule 5).
- The person decides (Hard rule 7).
