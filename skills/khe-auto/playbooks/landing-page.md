# Landing page

**You own this from a blank page to a reviewed one.** A marketing page tolerates more expression than product UI and less default, so the deletion pass is never optional.

1. **Check for a contract** with `khe-design-tokens`. If one exists it goes first and outranks every default below.
2. **Lay it out** with `khe-ui`, layout lane. A design per viewport, never a desktop page squeezed. Exit: the page frame holds at 390 and at 1440.
3. **Set the type** with `khe-ui`, typography lane. Exit: a closed scale named by role, a measure near 65 characters.
4. **Show the product** with `stageshow`. Frame a still first, at the size it will be seen and again at 390, before anything moves. Exit: its rehearsal gate passes.
5. **Explain a system, only if one needs explaining** with `khe-diagram`. Most pages need zero diagrams.
6. **Delete the defaults** with `khe-ui`, tells lane. Subtract first, then sweep. Exit: a numbered deletion list, applied.
7. **Review** with `khe-ui`, review lane. Exit: a verdict.

**Reply:** the verdict, what was deleted, what each product picture shows, and what still needs a real phone.
